# IKS & Precision Metrology --- Ancient Instruments, Modern Measurements

Indian Knowledge Systems (IKS) · Physics / SLA Project

**Live Website:** https://prabhleenkour.github.io/IKS_BPH_SLA/

## What's in this build

-   **Ancient Astronomical Instruments (Yantras)** --- an introduction
    to four traditional Indian instruments and their measurement
    principles:
    -   **Chakra Yantra** --- circular ring instrument used to study the
        declination and hour angle of celestial bodies.
    -   **Dhanur Yantra** --- bow / quadrant-style instrument for
        exploring angular measurement.
    -   **Yasti Yantra** --- staff or cross-staff used to understand
        elevation and angular distance.
    -   **Phalak Yantra** --- board instrument that uses the Sun's
        altitude to explore traditional timekeeping.
-   **Interactive Yantra Simulations** --- experiment with the
    instruments directly in the webpage:
    -   Drag the Chakra Yantra arm to read an angle.
    -   Adjust the Dhanur Yantra angle in 5° steps.
    -   Raise or lower the star in the Yasti Yantra simulation.
    -   Raise or lower the Sun in the Phalak Yantra simulation.
-   **Modern Precision Measurement Applications** --- interactive
    demonstrations of two laboratory instruments:
    -   **Vernier Caliper** --- move the scale or use fine-adjustment
        controls to measure an object's width. The displayed reading
        updates in real time.
    -   **Micrometer Screw Gauge** --- rotate the thimble using the
        controls to explore thickness measurement.
-   **Educational Focus** --- connects India's astronomical heritage
    with the measurement principles used in modern physics and
    engineering.

## Running the webpage

### Open the live version

Visit: https://prabhleenkour.github.io/IKS_BPH_SLA/

### Run locally

1.  Download or clone this repository.
2.  Open the project folder.
3.  Open `index.html` in a modern web browser.

This repository is a lightweight, browser-based webpage. No backend
server or package installation is required for the basic experience.

## Project objective

The aim of this project is to explore how traditional Indian
astronomical instruments were used to observe celestial objects and
measure angles, elevation, and solar altitude, then connect those ideas
with modern precision-measurement instruments.
